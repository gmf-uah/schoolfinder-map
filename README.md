# SchoolFinder Map

Build a web app (using WebGPU if applicable, WebGL backup) to show colleges, universities, high schools, and other educational institutions to the user on a map of the United States. Ideally the map is done by a library because making a whole mapping application is ambitious and unnecessary. The user can zoom in and out to reveal institutions according to their size or prominence/prestige. Each institution's icon can be inside a white box consisting of their logo and colors, if applicable. Clicking on an institution shows a dialog box with some info like the name, address, institution type (college, high school etc).
